{{ _('import_comic') }}

Import comic metadata from an external URL. This will scrape the title, description, and cover image. You can then edit the comic and add chapters manually.

How it works

  1. Enter the URL of the comic page you want to import
  2. The system fetches the page and extracts title, description, and cover image
  3. A new comic is created with the scraped data
  4. You can then edit the comic to add genres, fix details, and add chapters
  5. Chapters must be added manually with image URLs
