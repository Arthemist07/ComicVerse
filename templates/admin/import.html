Import comic metadata from an external URL. This will scrape the title, description, and cover image. You can then edit the comic and add chapters manually.

How it works

  1. MangaDex: Enter a MangaDex title URL or UUID → fetches title, description (EN+ID), and cover via MangaDex API
  2. Other sites: Enter any comic page URL → scrapes title, description, and cover image
  3. A new comic is created with the scraped data
  4. You can then edit the comic to add genres, fix details, and upload chapters
  5. Chapters can be created by uploading image files directly
